# FlintTrade v0.6.0-alpha - Restructure, release hygiene, and terminal wiring

FlintTrade `v0.6.0-alpha` is an alpha release for the restructured public repository. It is not production ready. The release focuses on making FlintTrade an independent app with its own backend, shared UI core, public website, generated docs/MCP surfaces, and optional OpenAlgo-compatible integration path.

## Release Metadata

- SemVer: `0.6.0-alpha`
- Git tag: `v0.6.0-alpha`
- Release type: alpha prerelease
- Stability: experimental, not production ready
- Primary app surfaces: terminal, backend, public site, docs MCP, shared design system

## Highlights

- Restructured the repository into `packages/apps`, `packages/core`, `packages/integrations`, and `packages/services`.
- Centralised product versioning through the root `VERSION` file, terminal version helpers, backend version helpers, and generated site metadata.
- Promoted `packages/core/design-system` as the shared UI core for tokens, layers, brand primitives, and reusable React components.
- Kept OpenAlgo as an optional external integration instead of a bundled runtime dependency; FlintTrade runs its own backend on port 5100.
- Added the public Next.js/Fumadocs site with generated docs, package pages, release pages, llms files, and a read-only contribution MCP.
- Added repository-level alpha disclaimer language covering production readiness, trading risk, no-advice boundaries, and user responsibility.

## Terminal And UX

- Restored the original welcome reveal direction with smoother particles and logo timing.
- Fixed Explore and Demo mode separation so Explore remains an explanation/onboarding route and Demo can enter the app intentionally.
- Fixed the Settings select crash caused by empty Radix Select item values.
- Reworked overlay stacking so popovers, command palette, notification centre, connection overlay, and floating panels share the design-system layer scale.
- Wired Home widgets so add, remove, preset, drag, reorder, and resize interactions are implemented and tested.
- Added Ditto account CRUD helpers and UI actions backed by FlintTrade backend routes.
- Improved connection, setup, and demo tests around the terminal flows that previously looked implemented but were not fully wired.

## Backend And Operations

- Updated Makefile, systemd, cron, deployment, rollback, health, status, and reset-state helpers to start and monitor FlintTrade first.
- Treated OpenAlgo as optional in docs and ops scripts while preserving the OpenAlgo-compatible REST/WebSocket bridge.
- Added version helpers in `flinttrade_core` so backend logs and app startup use the central product version tag.
- Added restructure regression tests to catch old paths, stale workflow references, missing package READMEs, optional OpenAlgo drift, and shared design-system delegation.

## Website And Docs

- Updated the public README, architecture guide, developer guide, setup quickstart, CI notes, API reference, package READMEs, issue templates, and release notes for the v0.6.0-alpha repo shape.
- Removed outdated references to the old top-level package layout, bundled OpenAlgo startup, Chrome extension package, and Tauri desktop package.
- Added `disclaimer.md` and surfaced it in the repository README, docs index, generated site docs, and website hero.
- Added current screenshot assets for the terminal routes and stopped referencing deleted transient screenshots.

## Verification Notes

This alpha release has local verification for the touched frontend, backend route, docs, and repository-structure surfaces. It is still a prerelease and must be validated in paper mode before any broker-connected workflow is used.
