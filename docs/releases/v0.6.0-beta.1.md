# FlintTrade v0.6.0-beta.1 - Final app audit and release guardrails

FlintTrade `v0.6.0-beta.1` is a beta prerelease. It is not production ready.
This patch supersedes the historical `v0.6.0-beta` tag for public installer
publishing because the older tag predates the final setup, release, and
supply-chain fixes.

## Release Metadata

- SemVer: `0.6.0-beta.1`
- Git tag: `v0.6.0-beta.1`
- Release type: beta prerelease
- Stability: beta, not production ready
- Primary app surfaces: native desktop app, terminal UI, FlintTrade backend,
  release installers, setup/account flow

## Highlights

- Live-mode setup now verifies the PIN through `/ft-api/v1/auth/pin` and keeps
  the live-unlocked session token before the UI can enter Live mode.
- Normal password and 2FA login clears stale persisted Live UI state so a user
  cannot see Live mode while holding an explore-locked JWT.
- Explore-mode onboarding CTAs now send first-time users to account setup
  instead of protected Settings or the legacy setup route.
- The public docs site now includes the current beta release note in its
  generated release catalogue.

## Release And Installer Hardening

- Desktop release dispatch rejects a supplied tag if it points at an older
  commit than the workflow run, preventing stale installers from being built
  under the current beta version.
- Supply Chain CI now audits both Rust lockfiles: the tick engine and the
  Tauri desktop app.
- The desktop Rust audit gate fails on vulnerabilities and on any new
  unreviewed warning. The currently reviewed warning-class Tauri GTK/WebKit
  stack advisories are tracked in `supply-chain/cargo-audit-allowlist.yml`
  with expiry dates.
- The desktop lock updates `anyhow` to the patched `1.0.103`; the remaining
  open Dependabot alert is the transitive `glib` 0.18 line held by Tauri's
  Linux GTK/WebKit stack.

## Verification Notes

The beta.1 patch was verified with focused terminal Vitest coverage for setup,
Explore, login, and mode switching; local desktop cargo audit coverage; and the
standard Python and terminal gates before tagging or publishing installers.
