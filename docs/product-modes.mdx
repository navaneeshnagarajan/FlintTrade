# Product Modes

FlintTrade distinguishes operating modes from data provenance. Provenance is independent of operating mode.

## Operating Modes

- **Explore**: sample-only discovery; no Live broker order authority. On `/trade`, Order Pad **Sample Buy** opens a sample review and records a local sample fill (no broker, order-proxy, or SafetySystem). Live-intent submits remain blocked.
- **Practice**: FlintTrade `SandboxEngine` fills (primary paper); no real broker order or capital movement. Orders are placed on `POST /api/v1/orders/place` after Laya admission. Square-off is that same place. Settings → Practice does not place. Restore of a Practice backup is Practice only; restored fills are tagged **Restored** and left out of Laya, strategy, benchmark, and training readers. Kotak Neo has no sandbox — never offer “Neo Practice”.
- **Live**: fail-closed until native Dhan + Neo Connected (read) is trusted and funded unlock is explicit. Connected (read) is a broker status, not a Mode. Non-funded live reads are never placeable Live orders. Live place is `POST /api/v1/orders/place`, `POST /api/v1/orders/<broker>/place`, or `POST /api/v1/orders/bracket` when the body has exactly one stop-loss or one target (Laya, then SafetySystem). Practice on the bracket route is HTTP 403 `practice_unsupported`. A broker-held variety, a stop-loss and a target together, and a trailing stop are refused before that admission. Every order FlintTrade submits goes through admission when it's placed. `"variety": "gtt"`, in any case or separator spelling, is HTTP 422 `gtt_unsupported` on that place, on routed place, on `POST /api/v1/positions/exit-all`, and on that bracket, before Laya, SafetySystem, and any broker call. The refusal is `Not placed. GTT orders aren't supported right now.` The Order Pad GTT option stays visible and disabled, with the tooltip `GTT orders aren't supported right now.` Exit-all requires a server reduce-only proof. Broker-connect helper copy may describe that read check as API smoke. Copy for Neo is `Live read only until funded unlock.` Laya is not Ready by default.

## Provenance Labels

- **Sample**: Synthetic or historical sample data for illustration.
- **Unavailable**: Data source temporarily unavailable.
- **Live**: Real-time live data.
- **Stale**: Data that has not been refreshed within expected freshness window. Stale requires a real freshness clock; this page describes the label, not a fake clock.

## Surface Ownership

- **Home**: Concise, read-only overview and discovery surface.
- **Trade**: Execution, charts, positions, orders, monitoring, and operational-risk controls.
