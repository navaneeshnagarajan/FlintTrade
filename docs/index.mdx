# FlintTrade Documentation (docs.page Pilot)

**Beta software. No financial advice. No promise of production readiness.**

This is a deliberately small, bounded docs.page MDX pilot. It demonstrates publication of representative pages without claiming a full Markdown to MDX migration of the canonical repository documents.

The canonical public FlintTrade documentation and the primary product surface remain on the existing Next.js site.

- [Getting Started](/getting-started)

All pilot content uses the canonical vocabulary: Modes **Practice** and **Live**; **Connected (read)** is a broker status, not a Mode; sample data labelled **Example**; the public web demo **Demo (example data)**; **Home** (concise/read-only) versus **Trade** (execution/charts/positions/orders); provenance **Sample**, **Unavailable**, **Live**, **Stale**; current catalogue of **71** widgets.

External links point only to public FlintTrade GitHub material under https://github.com/navaneeshnagarajan/FlintTrade .

## Provenance Independence Note

Mode (Practice and Live) is independent of data provenance (Sample/Unavailable/Live/Stale). Connected (read) is a broker status, not a Mode. Example is sample data, not a Mode. Practice does not imply Example data. Live mode does not guarantee a Live feed. Stale requires a real freshness clock; this page describes the label only.
