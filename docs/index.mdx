# FlintTrade Documentation (docs.page Pilot)

**Beta software. No financial advice. No promise of production readiness.**

This is a deliberately small, bounded docs.page MDX pilot on an isolated branch. It demonstrates publication of representative pages without claiming a full Markdown to MDX migration of the canonical repository documents.

The canonical public FlintTrade documentation and the primary product surface remain on the existing Next.js site.

## Provenance Independence Note

Operating mode (Explore/Practice/Live) is independent of data provenance (Sample/Unavailable/Live/Stale). Practice does not imply Sample data. Live mode does not guarantee Live provenance. Stale requires a real freshness clock; this page describes the label only.
