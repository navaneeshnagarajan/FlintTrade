# References and Credits

FlintTrade is an original AGPL-3.0 project, but it is built in the open and
learns from existing open-source trading, charting, UI, and agent projects.
This page is the public attribution surface referenced from the repository
README.

## Primary Influences

| Project / source | How FlintTrade uses the idea |
|---|---|
| [OpenAlgo](https://github.com/marketcalls/openalgo) | Optional OpenAlgo-compatible REST and WebSocket bridge, broker vocabulary, and Indian-market workflow references. FlintTrade now also has its own backend, sandbox, gateway, and native broker path. |
| [OpenClaw](https://github.com/openclaw/openclaw) | Agentic workflow and local-automation patterns. |
| [TradingView Lightweight Charts](https://github.com/tradingview/lightweight-charts) | Canvas chart rendering engine used inside the terminal. FlintTrade owns the shared chart theme and shell through `@flinttrade/design-system`. |
| [shadcn/ui](https://ui.shadcn.com/) and Radix UI | Accessible component primitives and copy-owned component patterns. |
| [Dockview](https://dockview.dev/) | Dockable terminal layout model. |

## Dependency Attribution

Runtime and development dependencies are listed in package manifests and lock
files. Their licences remain owned by their respective authors. Before a
dependency becomes part of a release, check the matching package manifest and
`LICENSE` files generated by the package manager.

## Internal Research Archive

Large research tables, competitive scans, and private working notes are kept out
of the public repository because they can include stale links, noisy notes, or
local-only context. Public docs should credit direct influences clearly without
shipping private research dumps.
