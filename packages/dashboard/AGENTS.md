# FlintTrade — dashboard

> Portfolio overview, P&L, market overview, system status

## Dev server port: 3000

## Absorbs
- stock-market-dashboard → React + Flask market dashboard
- trading-dashboard → Simple React trading dashboard
- openalgo-mobile → Flutter UI patterns → React responsive

## Rules
- React 19, Vite, Tailwind CSS
- This is the LANDING PAGE — first thing users see
- Branch: feature/dashboard-{description}

## Trade Journal (F8 module)
- Daily trade journal with mood tracking (confident/neutral/anxious/frustrated)
- Notes per trade — why entered, what went wrong, lessons
- Daily P&L summary with win/loss breakdown
- Time-of-day analysis — when do you trade best?
- Win/loss streaks tracking
- Export to CSV
