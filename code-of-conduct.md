# Code of Conduct

FlintTrade adopts the [Contributor Covenant](https://www.contributor-covenant.org/)
version 2.1.

**The full text lives at [.github/CODE_OF_CONDUCT.md](.github/CODE_OF_CONDUCT.md).**

It sits there rather than here because GitHub only surfaces a repository's Code
of Conduct — the banner on the repo home page, the link in the community
profile, and the prompt shown to first-time contributors — when the file is
named `CODE_OF_CONDUCT.md` in the root, `.github/`, or `docs/`. This repository
uses lowercase root document names, and `tests/test_restructure_goals.py`
enforces that. `.github/` satisfies both: GitHub finds the policy, and the root
stays lowercase.

Two copies of the same policy previously existed at the root, one under each
spelling, and they had already drifted apart. This file is a pointer so there
is one canonical text to keep current.

## Reporting

Report unacceptable behaviour through a
[GitHub Security Advisory](https://github.com/navaneeshnagarajan/FlintTrade/security/advisories/new)
or by opening an issue if the matter is not sensitive. See
[security.md](security.md) for the private-disclosure route.
